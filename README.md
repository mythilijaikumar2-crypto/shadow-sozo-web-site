# SHADOW SOZO — FLY TO HIGH

Premium cinematic scroll-driven storytelling web experience for **SHADOW SOZO**.

## 🌟 Brand Identity
- **Company**: SHADOW SOZO
- **Hook**: FLY TO HIGH
- **Visual Identity**: Deep Black, Luxury Gold (`#D4AF37`), Metallic Silver (`#CBD5E1`)
- **Aesthetic**: Premium, cinematic, futuristic, minimal, international creative studio.

## 🚀 Tech Stack
- **React 18** + **TypeScript**
- **Vite** (Lightning fast dev & build tool)
- **Tailwind CSS** (Custom luxury color tokens)
- **GSAP & ScrollTrigger** (Single master progress scroll controller)
- **Lenis** (Inertia smooth scrolling)
- **Lucide React** (Minimal icons)

## 🎬 Core Experience
- **Scroll-Driven Master Video Scrubbing**: Single normalized progress controller (`masterProgress` 0.0 -> 1.0) connecting scroll progress directly to `video.currentTime`.
- **7 Synchronized Cinematic Scenes**:
  1. `0% - 10%`: SHADOW SOZO Opening + Logo + FLY TO HIGH
  2. `10% - 25%`: EVERYTHING STARTS IN THE SHADOW.
  3. `25% - 42%`: TURN VISION INTO EXPERIENCE.
  4. `42% - 62%`: DESIGN. DEVELOP. GROW.
  5. `62% - 78%`: DON'T STAY WHERE YOU STARTED.
  6. `78% - 92%`: RISE. GO HIGHER.
  7. `92% - 100%`: FLY TO HIGH (Grand Climax + Logo Hold state)

## 🛠️ Local Development & Build

### Install Dependencies
```bash
npm install
```

### Start Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```
